# 🧹 Очистка репозитория Git

## Проблема
В репозиторий попали служебные файлы (bin, obj, и другие), которые не должны отслеживаться Git.

## ✅ Решение

### Шаг 1: Добавлен .gitignore
Создан файл `.gitignore` со стандартными правилами для .NET проектов.

### Шаг 2: Очистите кеш Git
Выполните команды в корне проекта:

```powershell
# Удалите все файлы из индекса Git (но не из файловой системы)
git rm -r --cached .

# Добавьте файлы заново (теперь с учетом .gitignore)
git add .

# Зафиксируйте изменения
git commit -m "Добавлен .gitignore и удалены служебные файлы"
```

### Шаг 3: Отправьте изменения
```powershell
git push
```

---

## 📋 Что будет игнорироваться

После применения `.gitignore` следующие файлы и папки **не будут** отслеживаться Git:

### Сборочные файлы
- `bin/` - скомпилированные файлы
- `obj/` - промежуточные файлы компиляции
- `*.dll` - библиотеки
- `*.exe` - исполняемые файлы
- `*.pdb` - файлы отладки

### IDE файлы
- `.vs/` - Visual Studio
- `.idea/` - JetBrains Rider
- `.vscode/` - VS Code (кроме настроек)
- `*.user` - пользовательские настройки

### Системные файлы
- `.DS_Store` - macOS
- `Thumbs.db` - Windows

### Конфигурация
- `.env` - переменные окружения (могут содержать пароли)
- `*.db` - базы данных SQLite

---

## ⚠️ Важно

После выполнения команд:
- Размер репозитория значительно уменьшится
- GitHub больше не будет жаловаться на большое количество файлов
- Каждый разработчик сможет иметь свои локальные настройки
- Пароли и секреты в `.env` не попадут в репозиторий

## 🎯 Проверка

После выполнения команд проверьте:

```powershell
# Посмотрите, какие файлы отслеживаются
git status

# Должно быть только:
# - Исходный код (.cs файлы)
# - Конфигурация (.csproj, .sln)
# - Docker файлы
# - README и другая документация
```
