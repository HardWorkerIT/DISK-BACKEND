# 🎯 Быстрая шпаргалка: Git команды для DiskAPI

## ✅ Ваша структура УЖЕ правильная

```
DiskAPI/              ← Git репозиторий (корень)
├── .gitignore        ← Создан
├── src/              ← Автоматически включён
│   ├── App/
│   ├── Common/
│   └── Modules/
└── ...
```

**Git автоматически отслеживает `DiskAPI/` и `src/`!**

---

## 📋 Команды для очистки и отправки

Выполните в **PowerShell** в папке `DiskAPI`:

```powershell
# 1. Очистите кеш
git rm -r --cached .

# 2. Добавьте файлы заново (с учётом .gitignore)
git add .

# 3. Проверьте, что добавилось
git status

# 4. Закоммитьте
git commit -m "Добавлен .gitignore и удалены служебные файлы"

# 5. Отправьте на GitHub
git push
```

✅ `.gitignore`  

❌ `bin/`, `obj/` (исключены)
